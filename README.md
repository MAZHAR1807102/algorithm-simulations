# Algorithm Simulations

Interactive, step-by-step algorithm simulations for teaching.

Sorting

- [Insertion Sort](https://mazhar1807102.github.io/algorithm-simulations/insertion-sort/)
- [Bubble Sort](https://mazhar1807102.github.io/algorithm-simulations/bubble-sort/)
- [Counting Sort](https://mazhar1807102.github.io/algorithm-simulations/counting-sort/)
- [Merge Sort](https://mazhar1807102.github.io/algorithm-simulations/merge-sort/) (Lecture 4)
- [Quick Sort](https://mazhar1807102.github.io/algorithm-simulations/quick-sort/) (Lecture 5)

Searching

- [Search Algorithms: Blind and Heuristic](https://mazhar1807102.github.io/algorithm-simulations/search/): BFS, DFS, UCS, DLS, IDS, bidirectional, greedy best-first, A*, hill climbing

Graphs

- [Shortest Paths](https://mazhar1807102.github.io/algorithm-simulations/shortest-path/): BFS, Dijkstra, Bellman–Ford, DAG, Floyd–Warshall, Johnson
- [Minimum Spanning Trees](https://mazhar1807102.github.io/algorithm-simulations/mst/): Kruskal, Prim, Borůvka, reverse-delete

Strings and arrays

- [String Matching](https://mazhar1807102.github.io/algorithm-simulations/string-matching/): naive, Rabin–Karp, automaton, KMP, Boyer–Moore–Horspool, Z
- [Prefix and Suffix Sums](https://mazhar1807102.github.io/algorithm-simulations/prefix-sum/): range queries, difference arrays, 2-D, applications

Plain HTML, CSS and JavaScript; no build step. Open any `index.html` in a browser.
